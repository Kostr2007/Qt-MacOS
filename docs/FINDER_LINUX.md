# Finder-подобное окно на Linux

8 ноября 2026. Реализация визуальной переделки из VISUAL_REWORK.ru.md.

## Что изменено

Вместо общей галереи Basic-контролов создана отдельная Finder-сцена:

- Оконная оболочка 1100×676 logical px с радиусом 13, обводкой и альфа-тенью;
  внешние 24 px служат полем для тени. Это не системная vibrancy.
- Sidebar 170 px (15.45% ширины видимого окна); Favourites, Locations, Tags.
  Выбранный Documents серый; начального выделения файла нет.
- Toolbar 66 px: навигация назад/вперёд, glyph-only кнопки, меню и поиск.
- Табличная строка 26 px вместо прежних 36; единые границы header и контента,
  размеры выровнены справа, чередующиеся полосы продолжаются до низа.
- Демонстрационные имена, даты и размеры соответствуют присланному референсу.
  Миниатюры — оригинальные рисунки, а не извлечённые фотографии или Finder assets.
- Inter Variable v4.1, OFL, закреплённый commit и checksum в assets/fonts/manifest.json.
  Это близкий переносимый шрифт, а не утверждение о совпадении с SF Pro.
- Новые масштабируемые Canvas glyphs, без зависимости от private Qt APIs,
  icon-font или GPU-only effects. Работают с software renderer.
- Кнопки окна подключены к реальным Window methods; перемещение/resize —
  QWindow.startSystemMove/startSystemResize. У maximized-окна нет отступа под тень.

Публичный библиотечный модуль и существующий пилот Obsidian не переделывались.
Новая сцена пока находится в demo, чтобы визуальную спецификацию можно было
проверить до обобщения в библиотеку.

контролируемый синий фон помогает видеть форму и тень. Он не является wallpaper

Последний снимок получен с X server через Pillow ImageGrab, без presentation mode;
фон виртуального рабочего стола чёрный.

При одинаковой ширине окна новая sidebar-доля и плотность таблицы близки к
оценкам референса: около 15.5% и 26 px при приведении к ширине 1100 px.
Точного процентного сходства не заявляем: исходный файл референса с метаданными
не доступен на диске, автоматическое совмещение/diff с ним не выполнялись.

## Проверки

Linux Debian 13, Qt 6.8.2, GCC 14.2, software renderer:

- CMake/Ninja build: PASS.
- qmllint всех demo QML: PASS, без предупреждений.
- CTest: PASS. Quick Test — 25 passed, 0 failed, 0 skipped;
  19 тестовых функций плюс 6 init/cleanup outcomes.
- Сохранены прежние проверки публичных контролов. Обновлены тестовые данные
  браузера под новую сцену; проверяются фильтр/пустая выдача, сортировка,
  клавиатура списка/сетки, отсутствие автоматического выделения, раскрытие поиска,
  меню темы, навигационная история и закрытие окна.
- Снимки dark/light/grid: PASS, просмотрены. Также выполнен screenshot run при
  QT_SCALE_FACTOR=1.5654545, что даёт видимой оболочке приблизительный raster size
  окна референса. Это не предположение о настоящем DPR исходного изображения.

Дополнительно запущены **настоящие X11 clients**: Xvfb 1400×900, Openbox и Picom.
Скрипт scripts/native_window_smoke.py нажимает кнопки мышью и проверяет реальные
состояния/геометрию окна, а не только факт отправки QML signal:

| Действие | Проверенный результат |
| --- | --- |
| Зелёная кнопка | 1148×724 → maximized 1400×900 |
| Повторное нажатие | Restore 1148×724 |
| Drag toolbar | Позиция (126,88) → (196,128) |
| Resize за угол | 1148×724 → 1078×684 |
| Жёлтая кнопка | Window state HIDDEN; затем успешно восстановлено |
| Красная кнопка | Процесс завершился с exit 0 |

Отчёт этого запуска: /tmp/finder-native-result.json; лог приложения пуст,
диагностических сообщений Qt нет. В начальном запуске smoke-скрипта обнаружена
ошибка аргументов xdotool для отрицательного смещения, исправлена через `--`;
последующий полный запуск прошёл.

Повторение в X11-сессии с оконным менеджером:

```sh
python3 scripts/native_window_smoke.py build/qtmacos-gallery /tmp/finder-result.json /tmp/finder-desktop.png
```

Нужны xdotool, xprop и Pillow для опционального снимка. Обычные QML/CTest тесты
не требуют этих инструментов. Wayland и другие оконные менеджеры этим прогоном
не подтверждены. Нативное системное backdrop blur ещё не реализовано.

## Запуск

```sh
source /workspace/qt-sdk/activate.sh  # только в подготовленной облачной машине
cmake -S . -B build -G Ninja
cmake --build build --parallel 4
./build/qtmacos-gallery
```

Поиск — Ctrl+F/значок лупы; Escape очищает и закрывает поиск. Тема — меню «…»
или Ctrl+Shift+L. Данные демонстрационные: приложение не является файловым
менеджером, не читает iCloud/AirDrop и не изменяет пользовательские файлы.
Share и назначение тегов отключены. Windows/macOS и полная интеграция этого
вида в Obsidian остаются отдельными этапами.
