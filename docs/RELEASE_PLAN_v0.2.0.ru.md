# План публикации 0.2.0

1. Сверить `main` на GitHub с локальной базой, сохранить существующую историю.
2. Обновить номер версии, README на двух языках, changelog, инструкции сборки,
   описание изменений и честные границы проверенных платформ.
3. Записать реальный Qt интерфейс: светлую/тёмную тему, навигацию, поиск и меню.
   Опубликовать выбранные PNG, MP4, короткий GIF и manifest происхождения.
4. Исключить SDK, сборки, загруженные референсы, локальные архивы и сырые сессии.
   Сохранить в репозитории исходники, тесты, лицензии и выбранные иллюстрации.
5. Проверить локальные ссылки и состав источников. Собрать библиотеку, галерею,
   тесты и независимый пример из чистого архива вне рабочего дерева.
6. Создать обычный коммит в `main`, сверить его дерево с подготовленным снимком.
   Проверить результаты CI, исправить подтверждённые ошибки сборки/тестов.
7. Опубликовать `v0.2.0` как pre-release. Проверить тег, архив исходников,
   SHA256SUMS и ссылки на демонстрационные материалы.

Текущий выпуск содержит исходники и демонстрационные материалы. Переносимые
пакеты приложения для Windows/macOS/Linux требуют отдельной упаковки и проверки.
